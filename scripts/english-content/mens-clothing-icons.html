When a store rejects SVG

Some store panels restrict SVG uploads because SVG can contain code. Use a transparent 512 px PNG where the panel requires a raster image and confirm the accepted size and format. If your theme supports SVG, test an inline or masked version on a copy before applying it across the store.

Match the catalog palette

Change fill values in a copy for a fixed banner. For normal, active, and unavailable states on the website, use a CSS mask with a color variable rather than duplicating files. The SVG color guide (Spanish) explains the methods. For printed catalogs and labels, edit the vector and check the print profile.

Example: categories people can name

Start with svg/oscuro/camisa.svg beside “Shirts” and svg/oscuro/corbata-01.svg beside “Ties.” These are white variants for a dark background. Keep the labels even when the navigation becomes compact.

If the label already names the link, use an empty image alt="" to avoid announcing it twice. Give the selected category a visible state beyond color, retain keyboard focus, and test long labels such as “Long-sleeve shirts.” Compare shirt and polo silhouettes at 20–24 px; a small collar detail alone may not distinguish them.

Questions before downloading

Why are some garments represented more than once?

The variants show different cuts and angles. Choose the drawing that fits the category and composition rather than assuming every variant is a new garment type.

What size are the PNGs?

512 × 512 px, with transparency and both variants. The original preparation regenerated these from SVG.

Can I change the color from CSS?

Use a CSS mask for a single-color silhouette, or inspect fills in inline SVG. An external image does not automatically inherit the surrounding text color.
