# Scene illustrations

Original Lienzo SVG illustrations with motion defined in CSS. No paths, artwork, code, or remote images are copied from the supplied six-icon reference. The reference and the user's 17 October video establish the six subjects and the expected richness of composition.

`scenes-art.js` creates six illustrations in a 360 × 260 viewBox. The keyboard has a machined case and independently animated keycaps. The stopwatch has a metal rim, engraved markings and a glass cover. The editorial scene uses layered ridges, a raised chart and a beveled conversation panel. The responsive scene uses metal bezels and a folded glass detail across three screens. In the connections scene, colored packets travel between glass cards and a graphite terminal. The lightbulb uses a translucent envelope and a threaded socket.

Original gradients live inside each SVG and get unique IDs so the collection, detail view and standalone export can render the same artwork together. The artwork uses no filters or external assets.

`scenes-art.css` controls individual mechanisms through `--scene-color`, `--cs-speed`, and `--cs-energy`. The controller supplies `--cs-play`, pauses offscreen and system-reduced motion, and manages explicit replay and the guided sequence. Continuous rotation is limited to mechanical parts. Other parts have separate rhythms.

Illustrations are inline SVG with CSS animation. They are not raster previews, video loops, or a claim that all drawing is made from CSS boxes. The interface labels this explicitly. Font notices and the new code license accompany the ZIP and standalone HTML export. Do not extend those notices to reference sources.
