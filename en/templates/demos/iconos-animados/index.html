How to use these icons

Paste the SVG inline in your HTML to trigger motion with pointer or focus. To use it as an image, choose Once on load or Gentle loop; an SVG inside img does not receive its parent element’s hover. Use the static format for a non-animated detail. Exported SVGs honor system reduced motion; pausing this demo does not change your export format. Settings last only for this visit.
