02 / INFORMATION

A percentage is a commitment.

If you cannot calculate progress, use an indeterminate indicator. When you can, keep the visual value, text, and accessibility attributes synchronized. Confirm an outcome with an explicit state.

When should I use each pattern?

A skeleton previews a known layout; an indeterminate indicator communicates activity when you have no reliable measure. Use a progress bar or percentage ring only when your app knows the actual progress. Avoid unnecessary indicators for immediate responses.

Does the simulation represent a real download?

No. Simulate demo runs a local sequence to review the waiting and final states. It does not measure network activity, files, or server tasks. In your app, connect setProgress to real progress and use setState to communicate the outcome.

What is exported, and how do I integrate it?

The separate HTML, CSS, and JavaScript match the same configuration. Insert the markup, add the styles, and load the runtime once. LienzoLoading.mount(element) returns setState, setProgress, setPaused, simulate, cancel, and destroy. The HTML example combines everything in one file and needs no CDN. Fonts use system fallbacks when unavailable.

How is the state communicated accessibly?

aria-busy identifies the region that is waiting. The status message sits outside that region so it can be announced. Known progress includes a synchronized aria-valuenow; indeterminate progress omits it. Decorative skeletons are hidden from assistive technology. Check the text in the context of your interface.

What happens with reduced motion and pause?

Reduced motion keeps indicators still while retaining their text information. Pause controls the animation and local simulation, not an external task in your app. The runtime also suspends the demo when the component is not visible. Keep the text that explains the wait.

Does 100% progress mean success?

Not by itself. setProgress(100) updates the value; setState('success') confirms the outcome. This lets you validate or finalize a task before showing it as complete. The error state includes a text explanation and retry action; connect that action to your app's logic.

What does the JSON project save?

It saves the pattern and settings so you can reopen them in Loading Studio. It contains no accounts, user files, operation data, or cloud synchronization. Accepted project files have a maximum size of 64 KiB and a known versioned schema.
