Abre, cambia,
hazlo tuyo.

  1. Prueba antes de descargar.La ventana de vista previa permite alternar escritorio, móvil y tema claro u oscuro. Usa el teclado, las flechas o los controles de la propia demo.
  2. Abre el ZIP en tu equipo.Descomprime la carpeta completa y abre index.html. No necesitas instalar paquetes: HTML, CSS y JavaScript están incluidos.
  3. Personaliza el contenido.Cambia los enlaces y textos en index.html y los colores al principio de styles.css. LEEME.md explica cómo integrar solo el componente.
  4. Conserva los créditos.El código se entrega con MIT. Mantén los avisos de autoría y los textos de licencia al redistribuirlo. Sustituye el logo de muestra por el de tu proyecto.
¿Qué mejoró en las versiones de Lienzo?

Los botones usan SVG locales en lugar de Font Awesome, incluyen nombres accesibles, foco visible y estilos para movimiento reducido. Se corrigieron las rutas y la estructura del HTML. El carrusel es código propio con desplazamiento nativo, navegación por teclado, botones anterior/siguiente, indicador de posición y filtro de favoritos.

¿Puedo usarlas en una web comercial?

El código incluido se distribuye bajo MIT, cuyos avisos se conservan dentro de cada ZIP. Las fuentes tienen sus propias licencias OFL. Revisa esos archivos y conserva los créditos al redistribuir. Los logos de redes y el logo de ejemplo conservan sus derechos de marca.

¿Funcionan en React, WordPress o una página HTML?

Son archivos HTML, CSS y JavaScript independientes. Puedes abrir la demo directamente o integrar el componente. En React debes adaptar los atributos a JSX y montar los listeners dentro del ciclo de vida del componente; en WordPress necesitas una zona que permita HTML, CSS y scripts. El ZIP no es un tema instalable de WordPress.
