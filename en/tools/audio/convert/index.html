Choose an audio output for your next step

This converter decodes a local file with the browser's Web Audio API. It exports 16-bit PCM WAV or, when supported, compressed audio through MediaRecorder. It does not upload your audio, offer an MP3 encoder, or restore details already lost in a compressed recording.

Convert, preview, and verify

  1. Drop a file or select it from your device. MP3, WAV, M4A/AAC, OGG, and FLAC input support depends on your browser and the actual codec, not just the filename extension.
  2. Check the waveform, duration, decoded sample rate, and original size. Play a section before converting.
  3. Choose WAV for an editing workflow. Choose the compressed option when your receiving app supports the format your browser can record.
  4. Keep stereo for spatial effects or music. Select mono deliberately for a voice recording: the tool averages the channels, which can alter stereo material.
  5. Download and open the result in the intended editor or player. Listen to the beginning and end, and compare its duration with the original.

WAV size: a calculation you can check

For this tool's PCM output, file size is 44 + frames × channels × 2 bytes. A 10-second buffer at 48,000 Hz contains 480,000 frames: stereo is 1,920,044 bytes, and mono is 960,044 bytes. These are calculated examples, not promised compression results. Your output follows the decoded sample rate shown by the tool, which may differ from the source rate.

What does “compressed” download?

The tool checks audio/webm;codecs=opus, then audio/ogg;codecs=opus, then the browser's audio/webm support. The extension is .webm or .ogg, rather than an MP3 with a renamed extension. The generic WebM fallback does not explicitly select a codec. If recording is unsupported, the secondary compressed download is hidden; use WAV.

Compressed export records playback, so allow approximately the audio's duration and keep the tab open. The displayed compressed size is an estimate; the encoder chooses the actual result. There is no universal “10 times smaller” guarantee or adjustable bitrate control here.

Use WAV when exact sample boundaries matter. Native compressed recording can change the timing at the edges: in our Chromium check, a one-second test decoded to 0.96 seconds. Check the downloaded beginning and ending before using compressed output for synchronized effects or seamless loops.

Does converting MP3 to WAV improve quality?

No. WAV makes the decoded audio available for editing, but it cannot recover discarded MP3 information. This exporter writes 16-bit PCM; it is not an archival, bit-for-bit copy of a higher-resolution original. Keep your source file.

Why does a file fail to load or export?

The browser may not support its codec, or the device may lack memory for the decoded audio and output buffer. Try a shorter file in a current browser. Renaming an extension does not convert a file. Use a desktop editor for unsupported formats or long sessions.
