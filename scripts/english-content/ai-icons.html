Choose a style at its real size

Flat color gives a hero section or presentation a distinct visual anchor. Outline fits labeled features and menus. Solid can hold its silhouette better in compact controls, but check every symbol at the intended size rather than assuming it will work as a favicon.

These real files are in svg/plano/robot.svg, svg/contorno/chatbot.svg, and svg/solido/red-neuronal.svg. Keep a visible label for every action.

Control one color with CSS

A mask works for outline and solid silhouettes. Add <span class="robot-icon" aria-hidden="true"></span> beside the label. Paths are relative to your stylesheet.

.robot-icon {
  display: inline-block;
  width: 32px;
  height: 32px;
  background: #35d6c8;
  -webkit-mask: url("svg/contorno/robot.svg") center / contain no-repeat;
  mask: url("svg/contorno/robot.svg") center / contain no-repeat;
}

A mask discards the flat style's multiple colors. To recolor that style, edit its individual fill values or internal style rules. Use external <img> elements for several flat icons to isolate their internal CSS classes. For inline outline or solid SVG, inspect all fills before replacing them with currentColor.

Questions before downloading

Are these 75 different icon concepts?

No. There are 25 concepts, each drawn in three styles. That produces 75 SVGs and 75 PNGs.

Can all three styles use the same recoloring method?

No. Outline and solid are single-color designs; flat color uses multiple fills. A CSS mask turns any style into one silhouette and does not preserve the flat palette.

What size are the PNGs?

128 px in each style. Export the SVG if you need a larger raster version.
