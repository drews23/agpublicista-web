Descarga los doce SVG con los ajustes que acabas de crear. Cada uno conserva su tamaño, color, trazo y forma de activarse.

Cómo usar estos iconos

Pega el SVG en tu HTML para activar el gesto con cursor o foco. Para usarlo como imagen, elige Una vez al cargar o Bucle suave; un SVG en img no recibe el hover del elemento exterior. El formato estático sirve para un detalle sin animación. El SVG respeta el movimiento reducido del sistema; la pausa de esta demo no cambia el formato exportado. Los ajustes se guardan solo durante esta visita.
