What is a Spline project?

A .spline file is editable source for Spline, not a rendered picture. It contains the scene structure so you can change materials, lights, camera framing, text, or animation. Open Spline and import a copy. The model construction is already done, but you still need to learn the controls relevant to your changes.

What's in the ZIP?

A render and a scene solve different problems

A render is a finished image with colors, shadows, and framing already chosen. An editable scene lets you change the material to a brand color, move the camera for a vertical crop, or revise the animation. Keep the original project as a master and save client changes in a duplicate.

From the project to a web page

  1. Open the selected .spline project in the editor.
  2. Adjust materials, text, camera, and animation for your page.
  3. Use Play to check the result.
  4. Use the web export option appropriate to your project and account. Follow the generated integration rather than treating the editable project as a web page.

For a canvas-based workflow, read embedding Spline without an iframe. A locally served scene can still need a remote runtime. Logo visibility and available export options remain subject to Spline's current conditions.

Choose interactive scene, 3D model, or render

Keep a web scene when the interaction helps explain your message. For another 3D viewer, inspect a GLB or glTF export. For a static header, use a render instead of loading an interactive player.

GLB does not preserve all Spline features: states, events, and physics do not transfer; supported timeline animation is limited to position, rotation, and scale. Materials and textures have limits too. Check the official GLB export documentation and inspect the result in the destination viewer. The pack does not include newly verified GLB conversions.

Before publishing

  • Choose a single scene for the message rather than loading all five together.
  • Test framing, text readability, scroll, and touch on a real phone.
  • Preserve the original project and offer a static image if live rendering is unnecessary or unavailable.

Frequently asked questions

Do I need to model the objects myself?

No. The source projects are already arranged, lit, and animated. Customize a copy in Spline. Available export features depend on your current account.

Are the downloaded files web-ready GLB models?

No. This pack contains editable .spline projects, cover images, and Spanish documentation. Export and inspect a GLB separately if your workflow requires that format.

Can I use a scene in professional work?

Consult the Lienzo resource terms and preserve individual authorship notices. The site operator declares authorization to distribute the collaborative work. This English documentation does not establish new rights or remove Spline's own export conditions.
