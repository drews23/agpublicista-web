Why separate the objects?

Opening a combined composition to delete seven objects can mean navigating layers and risking changes to lighting or cameras. The source preparation separated the pieces while retaining their geometry, materials, lighting, camera, and floating motion, according to the documented checks in the original guide.

Position matters: individual objects retain their coordinates from the combined scene. An object may appear off-center when first opened. Adjust its position or camera in a copy instead of assuming the file is empty.

What the editable format gives you

A Spline project contains objects, materials, lighting, cameras, and animation rather than a finished image. Change a material to a brand color, reframe for a vertical layout, or revise the motion. Keep the original as a master; a project-specific copy is easier to restore than overwritten source.

From a file to your website

  1. Open Spline and import the selected .spline project.
  2. Adapt the colors, text, materials, camera, or motion.
  3. Use Play to inspect the result.
  4. Choose the web export workflow appropriate to your project and account.

Review the current Play Settings, including renderer and page-scroll behavior, and test your target devices. See the canvas integration guide if you need an alternative to a public-page iframe. Serving a scene file yourself does not remove the runtime dependency or branding conditions.

If you need GLB instead

Export the selected piece from Spline and inspect it in your target viewer. Do not assume events, animation, lighting, and materials transfer unchanged. The five-scene guide explains the format choices and links to Spline's export limitations. These ZIPs contain editable projects, covers, and documentation; they do not contain verified GLB versions.

Combined composition or a single object?

  1. Define the space and purpose of the scene before changing the camera.
  2. For a page introducing several services, compare the combined composition against the heading. For one service card, start with its individual object.
  3. Publish the selected version and measure scene, textures, and runtime with cache disabled. ZIP size is not web transfer size.
  4. Check phone scrolling. If interaction adds little, use the object's cover or a new render instead.

Avoid eight simultaneous live viewers in a list. The load-and-stop example demonstrates lifecycle control using the data-charts scene from the other, five-scene pack; it is not a demonstration of these eight objects.

Frequently asked questions

Can I download only one scene?

Yes. Each object has a separate archive and download link. The complete ZIP is an alternative containing the eight individual scenes plus the combined scene.

Do individual scenes keep their animation?

The original preparation guide states that each keeps its camera, lighting, and floating motion. Their original coordinates may leave an object off-center; adjust its position or framing in a copy.

Can I open the project directly in another 3D viewer?

The .spline files are editable Spline projects. Use an appropriate export for another viewer and inspect it there; the pack does not include verified GLB conversions.
