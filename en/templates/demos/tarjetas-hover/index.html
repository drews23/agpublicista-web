FROM GESTURE TO PROJECT

Try it. Tune it. Make it yours.

Compare a surface at rest with its response. Customize the content, light, and timing, then bring working HTML to your website.

No dependencies. CSS, JS, fonts, and licenses included.

Use it in your project

Extract the ZIP and open index.html. Use Customize to edit each card. Exported HTML needs styles.css, script.js, and assets/ beside it. Without JavaScript, hover and focus retain CSS effects; the editor and touch preview need the script. Changes stay in memory and reset on reload.
