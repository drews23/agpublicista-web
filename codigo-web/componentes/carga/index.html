02 / INFORMACIÓN

Un porcentaje es un compromiso.

Si no puedes calcular el avance, utiliza un indicador indeterminado. Cuando sí puedas, sincroniza el valor visual, el texto y los atributos accesibles. Un resultado se confirma con un estado explícito.

¿Cuándo conviene cada patrón?

Un esqueleto anticipa una estructura conocida; un indicador indeterminado comunica actividad cuando no tienes una medida fiable. Usa barra o anillo de porcentaje solo cuando tu aplicación conoce el progreso real. Evita indicadores innecesarios en respuestas inmediatas.

¿La simulación representa una descarga real?

No. Simular demo ejecuta una secuencia local para revisar la espera y el estado final. No mide red, archivos ni tareas del servidor. En tu aplicación, conecta setProgress al avance real y usa setState para comunicar el resultado.

¿Qué se exporta y cómo se integra?

HTML, CSS y JavaScript separados corresponden al mismo ajuste. Inserta el marcado, añade los estilos y carga el runtime una sola vez. LienzoLoading.mount(elemento) devuelve setState, setProgress, setPaused, simulate, cancel y destroy. El ejemplo HTML reúne todo en un archivo y no necesita CDN. Las tipografías usan alternativas de sistema si no están disponibles.

¿Cómo se comunica el estado de forma accesible?

aria-busy identifica la región que está esperando. El mensaje de estado se coloca fuera de esa región para poder anunciarlo. Un progreso conocido incluye aria-valuenow sincronizado; uno indeterminado lo omite. Los esqueletos decorativos se ocultan a la tecnología de asistencia. Comprueba los textos en el contexto de tu interfaz.

¿Qué ocurre con el movimiento reducido y la pausa?

La preferencia de movimiento reducido mantiene los indicadores estáticos, con su información textual visible. Pausar controla la animación y la simulación local, no una tarea externa de tu aplicación. El runtime también suspende la demostración cuando el componente deja de ser visible. No elimines el texto que explica la espera.

¿Un progreso del 100 % significa éxito?

No por sí solo. setProgress(100) actualiza el valor; setState('success') confirma el resultado. Esto permite validar o finalizar una tarea antes de mostrar que terminó. El estado de error añade una explicación textual y una acción de reintento; conecta esa acción a la lógica de tu aplicación.

¿Qué guarda el proyecto JSON?

Guarda el patrón y sus ajustes para volver a abrirlos en Loading Studio. No incluye cuentas, archivos de usuarios, datos de una operación ni sincronización en la nube. Los archivos de proyecto admitidos tienen un máximo de 64 KiB y un esquema de versión conocido.
