# Expanding Panel Gallery — Lienzo

Five original SVG landscapes: valley, forest, dunes, architecture, and coast. Layered depth and small, distinct movements show how to present a collection, portfolio, or visual stories. Replace the sample content before publishing your project. Native HTML, CSS, and JavaScript; no installation, account, CDN, API, or third-party libraries.

## Get started

Extract the complete ZIP and open index.html. Click or tap a panel. Titles stay identifiable when panels are collapsed. You can also use the five indicators, Previous, and Next.

Responsive chooses the orientation for the available space. Horizontal and Vertical keep your preference when you resize. On small screens, horizontal mode scrolls inside the gallery instead of squeezing or hiding stories. Vertical mode lets the page scroll normally.

With a panel selector focused, use Left/Right in horizontal mode or Up/Down in vertical mode. Home and End select the first and last panels. Preview on hover is optional and requires a mouse or trackpad. Expand landscape opens a larger view with its own navigation, pause, and complete description. Escape closes it and returns focus.

## Customize each panel

Customize changes the title, category, description, HTTP(S) link, and accent. Reset item affects only that panel. The accent also appears in the original artwork.

Background and motion contains settings for the selected panel. Add a PNG, JPEG, or WebP up to 8 MB; processing stays in your browser without uploading it to a server. Adjust horizontal/vertical position and zoom. Add an accessible description when your photo conveys information. Use original artwork restores the landscape. An older pending image load cannot overwrite a more recent upload or restoration.

Depth and motion sets intensity; zero produces a still composition. Cycle duration changes the pace. Only the active panel animates. Manual pause, reduced motion, dialogs, and leaving the viewport suspend effects. Pointer updates run only when the pointer moves, without a permanent JavaScript frame loop. Performance depends on the device; no frame-rate guarantee is made.

## Keep and integrate your work

Settings live temporarily in memory. Reloading resets the example.

- **Get HTML** keeps the complete gallery with its photos and settings. Place it beside editor-workspace.css, editor-workspace.js, studio.css, studio.js, component.css, component.js, and assets/ from the ZIP. This export is not standalone.
- **Download this panel**, inside Background and motion, creates a standalone HTML file with the artwork or photo, styles, fonts, and notices. It works without neighboring files or a network connection. Pause, content, link, and framing are included. Added photos can increase the file size.

Keep license notices and accessibility features when integrating. The hosted demo uses noindex; downloads omit it. Set your own metadata before publishing. Sample links lead to Lienzo and should be replaced with the real destination for each story.

## Stable editing workspace

Open Settings to keep the preview beside the form. Apply commits content changes; Cancel discards unapplied fields. Hiding Settings preserves those fields. Image and motion controls update immediately and are labeled separately. Keep editor-workspace.css and editor-workspace.js beside the HTML, including when using a downloaded edited HTML.
