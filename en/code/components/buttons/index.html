Explore CSS components

Action, selection, or navigation.

A button triggers an action. Checkboxes allow independent choices; radios offer a single choice. Tabs switch panels. Styling should preserve that purpose.

State is content, too.

Distinguish focus, availability, and outcome through shape, text, and contrast. Reserve loading feedback for a real task. Keep the information when the user prefers less motion.

Are these functional controls or just a visual?

These use native button, checkbox, and radio elements, or tabs with linked buttons and panels. Selection, keyboard access, and states work. The lzc:action event connects a button to your process; lzc:change reports selection changes.

Does the async button download or submit a file?

Not by itself. The local demonstration is explicitly labeled. Connect your operation to the event and use setState to report loading, success, or error. The component does not claim an operation happened when it did not.

How do keyboard tabs work?

Tab enters the active tab. Left/Right Arrow navigate and activate panels; Home and End move to the first and last. Each panel keeps its ARIA relationship. Single and multiple choices retain native radios and checkboxes.

Do forced preview states remain in the code?

Hover, focus, and pressed are editor inspection aids. They are not exported as forced states. The disabled setting and explicit async-button states are preserved. Review the configuration before exporting.

Can I use several controls on the same page?

Yes. The runtime assigns independent identifiers and group names when mounting each component. Load the JavaScript once and use LienzoControls.mount or mountAll. destroy removes the component’s listeners and timers.

What do the download and project include?

The HTML example includes markup, styles, and JavaScript without a CDN. Each part is also available separately. JSON preserves settings for this studio; it is not an account or cloud synchronization. MIT code includes its license notice.
