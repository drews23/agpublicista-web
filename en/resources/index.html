Choose the format your project needs

  • SVG and PNG icons: choose SVG for scalable, editable vectors or PNG for an application that needs raster images. Styles, dimensions, and quantities vary by pack.
  • WAV sound effects: compare the inventory and demonstration in each guide. The 68-effects library spans six categories and is not a single archive.
  • After Effects projects: review the original tutorial and any stated font or dependency requirements before opening a copy of the project.
  • Spline scenes: editable .spline files require Spline. Each guide explains web integration and player dependencies.
  • Web templates: HTML, CSS, and JavaScript with live previews and separate downloadable ZIPs.
