01 / CSS
La animación y su contexto
Los @keyframes describen los cambios. La regla animation define duración, curva, retardo, repeticiones, dirección y estado final. El CSS mantiene el movimiento; el ejemplo HTML añade los elementos y la activación elegidos.


02 / UX
Secuencia antes que ruido
Prueba varios elementos con un intervalo corto para ordenar la atención. El retardo desplaza el comienzo completo; el intervalo escalona los elementos. Evita repetir continuamente efectos que compitan con la lectura.


¿Funciona sin JavaScript?
El movimiento exportado usa CSS nativo; la herramienta utiliza JavaScript para editar y controlar la vista previa. Al desplazar, el CSS emplea animation-timeline: view() donde es compatible. En otros navegadores, conserva el contenido visible y estático. El tiempo de esta muestra representa un recorrido de referencia; la exportación sigue el progreso del desplazamiento.


¿Qué ocurre con el movimiento reducido?
La vista previa empieza estática cuando tu sistema lo solicita y permite una reproducción explícita. La exportación incluye prefers-reduced-motion para evitar el movimiento y conservar el contenido visible. Comprueba el resultado en tu diseño y no elimines esa alternativa.


¿Son iguales todos los costes de renderizado?
No. Transform y opacity suelen ser un buen punto de partida. Más elementos, grandes superficies y propiedades que repintan pueden aumentar el trabajo del navegador. Las etiquetas orientan, pero no son una medición de FPS: prueba tu proyecto en dispositivos reales.


¿Qué conserva cada descarga?
CSS contiene el estilo y los keyframes para integrarlos en tu web. HTML es un ejemplo de la configuración actual; utiliza fuentes de sistema si Fraunces e Instrument Sans no están instaladas o cargadas en tu sitio. JSON guarda los ajustes para reabrirlos en este estudio; no contiene una cuenta ni sincronización en la nube. Guardar en Mi Lienzo conserva el CSS, no los controles.
