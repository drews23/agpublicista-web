What this test measures

These icons already have compact code, so file sizes may stay the same at precision 3. Try 0 and enlarge the curves and details to see the effect of rounding. If you change a setting, compare again before downloading the report.

The lab runs Lienzo's default optimizer plugins with multiple passes and no indented formatting. Your precision setting applies to coordinates. File sizes are UTF-8 bytes without HTTP compression; the report records the options and both files.

Fewer bytes do not prove that everything is unchanged. Inspect both drawings, including at their final size. This set does not test animation, fonts, accessibility, external CSS or scripts, or the safety of third-party files.

The JSON includes results and exact settings. The HTML comparison is a standalone snapshot with embedded drawings that opens offline. Visual review remains pending until you perform it.
