01 / CSS
The animation and its context
The @keyframes describe the changes. The animation rule defines duration, easing, delay, iterations, direction, and fill mode. CSS provides the motion; the HTML example includes your chosen elements and trigger.

    
02 / UX
Sequence before noise
Try multiple elements with a short stagger to guide attention. Delay shifts the whole start; stagger offsets individual elements. Avoid continuous effects that compete with reading.

    
Does it work without JavaScript?
Exported motion uses native CSS; the tool uses JavaScript to edit and control the preview. Scroll effects use animation-timeline: view() where supported. Other browsers keep the content visible and still. Timing in this preview represents a reference pass; exported motion follows scroll progress.

    
What happens with reduced motion?
The preview starts still when requested by your system and allows explicit playback. Exported code includes prefers-reduced-motion to avoid motion and keep content visible. Check it in your layout and retain that alternative.

    
Do all effects have the same rendering cost?
No. Transform and opacity are often a good starting point. More elements, large surfaces, and paint-heavy properties can increase browser work. Labels are guidance, not FPS measurements: test your project on real devices.

    
What does each download preserve?
CSS contains styles and keyframes for your website. HTML is an example of the current configuration; it uses system fonts if Fraunces and Instrument Sans are not installed or loaded on your site. JSON stores settings you can reopen in this studio; there is no account or cloud synchronization. Save to My Lienzo keeps the CSS, not the controls.
