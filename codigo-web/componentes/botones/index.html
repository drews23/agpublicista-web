Explorar componentes CSS

Acción, selección o navegación.

Un button ejecuta una acción. Un checkbox admite elecciones independientes; los radios ofrecen una sola. Las pestañas cambian paneles. La estética no debe alterar esa función.

El estado también es contenido.

Distingue foco, disponibilidad y resultado con forma, texto y contraste. Reserva una señal de carga para una tarea real. Si el usuario prefiere menos movimiento, conserva la información.

¿Son controles funcionales o solo una imagen?

Son elementos nativos: button, checkbox y radio, o pestañas con botones y paneles asociados. La selección, el teclado y los estados funcionan. El evento lzc:action permite conectar el botón con tu proceso; lzc:change informa los cambios de selección.

¿El botón de carga descarga o envía un archivo?

No por sí solo. La demostración es local y está identificada. Conecta tu operación al evento y usa setState para comunicar loading, success o error. No se promete una operación que no ocurrió.

¿Cómo funcionan las pestañas con teclado?

Tab entra en la pestaña activa. Flecha izquierda/derecha recorre y activa los paneles; Home y End van al primero y al último. Cada panel conserva su relación ARIA. Para opciones únicas y múltiples se mantienen radios y checkboxes nativos.

¿Los estados de prueba se quedan en el código?

Hover, foco y pulsado son ayudas de inspección del editor. No se exportan como estados forzados. La configuración deshabilitada y los estados explícitos del botón de carga sí se conservan. Revisa el ajuste antes de exportar.

¿Puedo usar varios controles en la misma página?

Sí. El runtime asigna identificadores y nombres de grupo independientes al montar cada componente. Carga el JavaScript una sola vez y usa LienzoControls.mount o mountAll. destroy elimina los eventos y temporizadores del componente.

¿Qué incluyen la descarga y el proyecto?

El ejemplo HTML incorpora marcado, estilos y JavaScript sin CDN. También puedes descargar cada parte. El JSON conserva tus ajustes y se abre en este estudio; no es una cuenta ni sincronización en la nube. Código MIT con su aviso incluido.
