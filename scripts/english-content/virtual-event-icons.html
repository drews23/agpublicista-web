Use the format your destination accepts

SVG is useful for the event website, editable slides, and scalable layouts. A 512 px PNG is practical for an image overlay or an application that does not accept SVG. Many email clients and event systems restrict vector uploads: check the destination and use PNG when needed. Avoid enlarging it beyond its working resolution.

Try the PNG as an OBS image source and record a thirty-second sample at your stream settings. Inspect it at delivery size; if details disappear, increase its visible size or choose a simpler silhouette. The two color variants do not change stroke thickness.

Apply the event palette

Inspect the SVG's fills in a copy before recoloring. Inline SVG can inherit text color when relevant fills use currentColor; external images do not inherit that color automatically. A CSS mask provides one-color control without editing each file. The SVG color guide (Spanish) explains the options.

Example: three webinar agenda actions

  1. Pair a calendar icon with “Add to my calendar.”
  2. Pair a video-call icon with “Join the room.” Before opening, show the start time; during the broadcast, change the label to “Join live.”
  3. Pair a microphone with “Submit a question.” Keep the text so it is not mistaken for a mute control.

On mobile, make the whole icon-and-label area clickable. Keep keyboard navigation in agenda order. Reminder emails also need useful text when images are blocked.
