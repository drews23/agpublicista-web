From signage to the booking interface

Use SVG in scalable signage and editable layouts. Print a proof at the final size and check it from the intended reading distance. If two symbols are difficult to distinguish, choose clearer drawings rather than relying on color alone.

For a booking interface, place amenity icons in consistent 24 or 32 px boxes and inspect their optical weight. Keep the service label visible. Use PNG in destinations that restrict SVG uploads; the pack's largest PNG is 96 px, so export from SVG when a larger image is required.

Match the hotel's identity

For print, change the fill in a vector editor and check the output profile. For the website, a CSS mask lets one file take its color from a brand variable. The SVG color guide (Spanish) explains static recoloring, inline SVG, and masks.

No. This pack contains 24, 48, and 96 px PNGs. Export the SVG at the required size if your destination needs more pixels.
