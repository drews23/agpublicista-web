From preview to your project

  1. Try the demo. Open the desktop or mobile preview and test its controls.
  2. Download the ZIP. Extract the full folder and open index.html in a modern browser. No package installation required.
  3. Customize the code. Change text and links in HTML, adjust the CSS variables, and adapt the JavaScript where needed.
  4. Keep the license notices. The code uses MIT; local fonts include OFL licenses. Sample logos retain their trademark rights.
